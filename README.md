# Perfume Place - Luxury Shopify Fragrance Store Redesign

A modern, ultra-premium Shopify homepage UI redesign for **Perfume Place India** ([perfumeplace.in](https://perfumeplace.in/)), taking architectural and department-structure cues from Perfume Palace while strictly retaining the authentic **Perfume Place** royal luxury brand identity.

---

## 🎨 Brand Design System & Palette

| Token | Hex Value | Role & Usage |
|---|---|---|
| **Champagne Cream** | `#FAF2E5` | Announcement bar, subtle section backdrops, sub-navigation bar, badges |
| **Regal Antique Gold** | `#AB7D28` | Primary accent, luxury CTAs, category active states, rating stars, borders |
| **Dark Gold** | `#8E651D` | Hover states, interactive highlights |
| **Charcoal Dark** | `#222222` | Editorial typography, headings, high-contrast badges |
| **Obsidian Black** | `#141414` | Ultra-luxury storytelling splits, primary footer background |
| **Mint Emerald** | `#10B981` | Verified batch tags, discount savings chips |
| **Paper White** | `#FFFFFF` | Clean product card containers, modal backdrops |

> **Strict Rule**: Zero generic navy blue (`#0C1033`). All headers, menus, announcements, and accents use Perfume Place's warm Champagne Cream and Regal Gold palette.

---

## ✨ Key Features & Sections

1. **Top Announcement Bar**:
   - Champagne cream ribbon with 10,000+ Happy Customers, 100% Original Products, and Free Pan-India Delivery alerts.
   - Fully responsive for mobile and desktop screens.

2. **Luxury Header with A-Z Mega Menu**:
   - Centered **Perfume Place** crest logo with `Maison de Parfum` subtitle.
   - Full-width multi-column Mega Menu featuring **60+ international designer houses arranged alphabetically (A–C, D–H, I–N, O–Z)**.
   - Dedicated dropdowns for Niche Houses (Creed, MFK, Parfums de Marly, Nishane) and Middle Eastern / Dubai Royal Houses (Lattafa, Afnan, Rasasi, Swiss Arabian).

3. **Modern Mobile Drawer & Fixed Bottom Bar**:
   - Smooth slide-in mobile drawer with real-time in-drawer search.
   - Accordion navigation for Designer, Niche, and Middle Eastern fragrances.
   - App-style fixed bottom navigation bar (`Home`, `Explore`, `Search`, `Wishlist`, `Cart`).
   - One-touch WhatsApp Scent Concierge CTA (`+91 98765 43210`).

4. **Curated Product Showcase Sections**:
   - **Section 1: Trending & Best Sellers**: Full **4x2 grid (8 products)** with working category filter tabs (`All Fragrances`, `New Arrivals`, `Arabian Royals`, `10ml Decants`).
   - **Section 2: New Arrivals & Trending Drops**: Interactive **horizontal slider carousel** with left/right arrow navigation and touch swiping.
   - **Section 3: Men's Signature Powerhouses**: Full **4x2 grid (8 products)** focusing on high-sillage masculine fragrances.
   - **Section 4: 10ml Discovery Decants & Travel Samples**: Interactive **horizontal slider carousel** dedicated to travel atomizers.

5. **Instagram Community Feed (`#PerfumePlaceIndia`)**:
   - Visual 6-post gallery showing authentic unboxing flatlays.
   - Responsive layout (2 columns on mobile, 3 on tablet, 6 on desktop).
   - Interactive overlays featuring likes, comments, and direct product price tags.
   - Community join banner for `@perfumeplace.in` (48K+ followers).

6. **Trust, Authority & E-Commerce Essentials**:
   - Direct Dubai import editorial storytelling split with CheckFresh verification guarantee.
   - Verified customer reviews & rating badge (4.92 / 5.0).
   - Interactive FAQ accordion covering authenticity, batch codes, transit insurance, and decant extraction.
   - Sliding Cart Drawer with live item calculation, promo codes, and free delivery threshold.
   - Olfactory Pyramid Quick View Modal (Top, Heart, Base notes visualization).
   - Ultra-premium Obsidian footer with SVG social icons and SSL trust badges.

## 🚀 Getting Started

Simply open `index.html` in any modern web browser or serve it locally:

```bash
# Using Python
python -m http.server 4123

# Or using Node.js
npx serve -l 4123 .
```

Navigate to `http://localhost:4123`.
